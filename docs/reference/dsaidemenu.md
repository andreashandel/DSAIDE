# The main menu for the DSAIDE package

This function opens a Shiny app with a menu that will allow the user to
run the different simulations.

## Usage

``` r
dsaidemenu()
```

## Details

Run this function with no arguments to start the main menu (a Shiny app)
for DSAIDE
